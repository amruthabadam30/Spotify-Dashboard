# Spotify-Dashboard


## 📌 Overview
This project is a **Spotify Dashboard** built using Python and Power BI to analyze and visualize music streaming data.  
It provides insights into:
- Top artists, albums, and tracks
- Genre distribution
- Listening trends over time
- Popularity scores and audio features (danceability, energy, tempo, etc.)

The goal is to demonstrate **data cleaning, analysis, and visualization skills** while creating an interactive dashboard for music lovers and analysts.
